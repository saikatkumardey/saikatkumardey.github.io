Once I got Claude Code Max plan, things changed.

I am addicted to building.

I have been coding for over a decade, building tools and utilities for my own usage.

With **Claude Code**, it is more fun than ever.

Typing code out has always been the bottleneck between my ideas seeing the light of the day or just getting discarded.

I am building more open source tools now - I start off with a conversation with Donna (my IndieClaw agent hosted on a VPS) and ask her to spec if out. Once the spec looks good, I ask it to build the first version. It spawns off a subagent (usually sonnet-4-6) that builds from the spec and hosts it on the VPS for me to check. Once it looks okay, I ask her to package it and publish it to my GitHub.

I no longer need to be on my laptop to build. I can build by just talking to Donna on telegram and will things into existance.

Right now, I am writing this post from a custom blogger webapp that will publish to my Github hosted blog. All built by just speaking to Donna.

My plan is to use this tool for a while and then open-source it for people to self-host. If I end up using this a lot, I will create a cloud-hosted option for people who don't want the hassle to self-host.
