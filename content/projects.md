Things I've built. Some useful, some just fun.

---

### [python-doctor](https://github.com/saikatkumardey/python-doctor)
CLI that gives your Python codebase a 0-100 health score. Security, lint, complexity, dead code, and more. Built for AI agents.

### [aidoc](https://github.com/saikatkumardey/aidoc)
Auto-generates documentation for Python projects. Point it at your codebase, get clean docs. Available on [PyPI](https://pypi.org/project/aidoc/).

### [quickreadai](https://github.com/saikatkumardey/quickreadai)
Key takeaways from non-fiction books, powered by AI. Try it [live](https://quickreadai.streamlit.app).

### [habithub](https://github.com/saikatkumardey/habithub)
A minimal habit tracker for iOS. Built in Swift because I wanted something that stayed out of the way.

### [tweetSpy](https://github.com/saikatkumardey/tweetSpy)
Real-time tweet monitoring dashboard. Track keywords, watch trends unfold.

### [interactive-dataviz](https://github.com/saikatkumardey/interactive-dataviz)
Interactive data visualization app built with Dash. Reactive charts, clean interface.
