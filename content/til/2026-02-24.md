title: "Every terminal SVG tool requires a live recording session"
---

All the popular tools — [svg-term-cli](https://github.com/marionebl/svg-term-cli), [termtosvg](https://github.com/nbedos/termtosvg), [MrMarble/termsvg](https://github.com/MrMarble/termsvg) — convert asciinema recordings to SVG. You have to actually run the commands first. There is no tool that takes a static config (YAML, TOML, whatever) and renders a fake terminal session as SVG — useful for README demos where you want a clean, controlled output without recording your messy real shell. So I built one: [termstage](https://github.com/saikatkumardey/termstage).
