- Hugo's content type is derived from the directory name. Content in `content/til/` automatically gets type `til`.
- Use `layouts/[type]/list.html` and `layouts/[type]/single.html` for custom rendering per content type.
- Menu items are added via `menu = "main"` in frontmatter. The nav.html partial iterates `Site.Menus.main`.
- TIL entries work best with minimal frontmatter—just date and optional title. Keep friction low.
- Bear Blog theme is minimal and clean; it uses CSS variables like `--text-secondary` and `--border` for theming. Good for dark mode support without extra work.
